FFmpeg und x264
Zum Lesen und Schreiben von Videos startet die App die eigenständigen Programme FFmpeg (Version 7.1) und x264. Beide stehen unter der GNU General Public License, Version 3. Du darfst sie nach den Bedingungen dieser Lizenz verwenden, weitergeben und verändern; sie kommen ohne jede Gewährleistung.

Den vollständigen Quelltext dieser beiden Programme samt Bauanleitung findest du unter https://thexmr.github.io/gearspark-recht/quelltext.html. Auf Anfrage an die Adresse im Impressum schicken wir ihn dir auch zu — für mindestens drei Jahre ab deinem Download der App.

Quelltext

FFmpeg 7.1, unverändert: ffmpeg.org/releases/ffmpeg-7.1.tar.xz
x264, Zweig „stable“, unverändert: code.videolan.org/videolan/x264

Beide Programme werden ohne eigene Änderungen am Quelltext gebaut. Sollten die Adressen oben einmal nicht erreichbar sein, schicken wir dir den Quelltext auf Anfrage an die Adresse im Impressum.

Bauanleitung

Mit diesem Skript entstehen die ausgelieferten Programme (Android NDK 27, arm64):

#!/bin/bash
# Baut ffmpeg und ffprobe fuer Android (arm64) und legt sie so ab, dass die
# App sie mitliefern kann.
#
# Warum ueberhaupt: die gesamte Medienstrecke von GEARSPARK ruft ffmpeg als
# Programm auf. Auf dem Schreibtisch ist es installiert, auf einem Telefon
# nicht — und nachinstallieren kann der Nutzer dort nichts. Also kommt es mit
# in die App.
#
# Warum als `lib*.so`: seit Android 10 darf eine App nur noch Programme
# ausfuehren, die im Bibliotheksordner des Pakets liegen. Dorthin gelangt eine
# Datei ausschliesslich, wenn sie wie eine Bibliothek heisst.
set -euo pipefail

HIER="$(cd "$(dirname "$0")" && pwd)"
BAU="$HIER/bau"
ZIEL="$HIER/../../app/gen/android/app/src/main/jniLibs/arm64-v8a"
API=26

: "${ANDROID_HOME:?ANDROID_HOME fehlt — zuerst 'source code/android-env.sh'}"
NDK="${NDK_HOME:-$ANDROID_HOME/ndk/$(ls "$ANDROID_HOME/ndk" | sort -V | tail -1)}"
WERKZEUG="$NDK/toolchains/llvm/prebuilt/darwin-x86_64"
[ -d "$WERKZEUG" ] || WERKZEUG="$NDK/toolchains/llvm/prebuilt/$(ls "$NDK/toolchains/llvm/prebuilt" | head -1)"

export PATH="$WERKZEUG/bin:$PATH"
export CC="aarch64-linux-android$API-clang"
export CXX="aarch64-linux-android$API-clang++"
export AR="llvm-ar" RANLIB="llvm-ranlib" STRIP="llvm-strip" NM="llvm-nm"

PREFIX="$BAU/prefix"
# ffmpeg fragt pkg-config nach x264. Ohne diese beiden Variablen sucht
# pkg-config in den Systemordnern des Macs und findet dort natuerlich nur
# Bibliotheken fuer macOS — die Fehlermeldung lautet dann irrefuehrend
# "x264 not found".
export PKG_CONFIG_PATH="$PREFIX/lib/pkgconfig"
export PKG_CONFIG_LIBDIR="$PREFIX/lib/pkgconfig"
mkdir -p "$BAU" "$PREFIX"
cd "$BAU"

X264_VER=stable
FFMPEG_VER=7.1

# 16-KB-Speicherseiten: Google Play verlangt sie seit November 2025 fuer Apps
# mit Ziel Android 15+. Das NDK richtet erst ab r28 von selbst so aus; die
# Angabe `-z max-page-size=16384` bei den Linker-Schaltern unten erzwingt es
# auch mit r27. Am Ende prueft `seitengroesse-pruefen.py` das Ergebnis.

# --- x264 --------------------------------------------------------------------
if [ ! -f "$PREFIX/lib/libx264.a" ]; then
  echo "== x264 wird geholt und gebaut =="
  [ -d x264 ] || git clone --depth 1 --branch "$X264_VER" https://code.videolan.org/videolan/x264.git
  cd x264
  ./configure \
    --prefix="$PREFIX" \
    --host=aarch64-linux-android \
    --cross-prefix="$WERKZEUG/bin/llvm-" \
    --sysroot="$WERKZEUG/sysroot" \
    --enable-static --enable-pic \
    --disable-cli --disable-opencl --disable-asm
  make -j"$(sysctl -n hw.ncpu 2>/dev/null || nproc)"
  make install
  cd "$BAU"
fi

# --- ffmpeg ------------------------------------------------------------------
echo "== ffmpeg wird geholt und gebaut =="
if [ ! -d "ffmpeg-$FFMPEG_VER" ]; then
  curl -L -o "ffmpeg-$FFMPEG_VER.tar.xz" "https://ffmpeg.org/releases/ffmpeg-$FFMPEG_VER.tar.xz"
  tar xf "ffmpeg-$FFMPEG_VER.tar.xz"
fi
cd "ffmpeg-$FFMPEG_VER"

if [ ! -f ffmpeg ]; then
  ./configure \
    --prefix="$PREFIX" \
    --target-os=android --arch=aarch64 --enable-cross-compile \
    --cc="$CC" --cxx="$CXX" --ar="$WERKZEUG/bin/llvm-ar" \
    --ranlib="$WERKZEUG/bin/llvm-ranlib" --strip="$WERKZEUG/bin/llvm-strip" \
    --nm="$WERKZEUG/bin/llvm-nm" \
    --sysroot="$WERKZEUG/sysroot" \
    --extra-cflags="-I$PREFIX/include -O2 -fPIC" \
    --extra-ldflags="-L$PREFIX/lib -static-libstdc++ -Wl,-z,max-page-size=16384" \
    --extra-ldexeflags=-pie \
    --pkg-config-flags=--static \
    --enable-gpl --enable-version3 --enable-libx264 \
    --enable-static --disable-shared \
    --enable-pic \
    --disable-doc --disable-ffplay --disable-debug --disable-symver \
    --enable-protocol=file,pipe --enable-filter=all \
    --enable-decoder=h264,hevc,vp8,vp9,aac,mp3,pcm_s16le,flac,vorbis,opus,png,mjpeg \
    --enable-encoder=libx264,aac,pcm_s16le,png,rawvideo \
    --enable-demuxer=mov,matroska,avi,mp3,wav,flac,ogg,image2,rawvideo \
    --enable-muxer=mp4,mov,matroska,mp3,wav,image2,rawvideo,null \
    --enable-parser=h264,hevc,aac,vp9,png
  make -j"$(sysctl -n hw.ncpu 2>/dev/null || nproc)"
fi

mkdir -p "$ZIEL"
cp ffmpeg "$ZIEL/libffmpeg.so"
cp ffprobe "$ZIEL/libffprobe.so"
"$WERKZEUG/bin/llvm-strip" "$ZIEL/libffmpeg.so" "$ZIEL/libffprobe.so" || true
chmod +x "$ZIEL/libffmpeg.so" "$ZIEL/libffprobe.so"

python3 "$HIER/../../produkte/seitengroesse-pruefen.py" "$ZIEL"

echo
echo "== fertig =="
ls -la "$ZIEL"
file "$ZIEL/libffmpeg.so" 2>/dev/null || true
